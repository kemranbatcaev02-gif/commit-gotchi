# Часто задаваемые вопросы (FAQ)

### 1. Как Commit-Gotchi узнает о коммитах?
Утилита выполняет стандартную команду `git log --since="midnight" --oneline` в текущей рабочей директории и считает количество строк. Если за сегодня были коммиты, питомец моментально становится сытым и счастливым!

### 2. Как сменить питомца по умолчанию?
Просто передайте флаг `--pet <вид>` при любой команде:
```bash
python gotchi.py --pet dino status
```
Выбор автоматически сохранится в файле конфигурации `~/.commit_gotchi_state.json`.

### 3. Где хранятся данные о настроении и поглаживаниях?
Вся статистика (уровень счастья, общее число поглаживаний, выбранный питомец) хранится локально в домашней директории пользователя в файле `.commit_gotchi_state.json`.

### 4. Как сбросить состояние питомца?
Используйте команду:
```bash
python gotchi.py reset
```
