# Руководство по участию в разработке (Contributing)

Мы будем рады, если вы захотите добавить нового виртуального питомца!

## Как добавить своего питомца:
1. Откройте файл `gotchi.py`.
2. Найдите словарь `PETS` и добавьте новый ключ (например, `"penguin"`).
3. Опишите 5 обязательных ASCII-состояний:
   - `godmode` (Режим бога при 20+ коммитах)
   - `super_happy` (От 5 коммитов)
   - `happy` (1-4 коммита)
   - `hungry` (0 коммитов)
   - `dead` (Спячка)
4. Добавьте юнит-тест в `tests/test_gotchi.py`.
5. Откройте Pull Request с описанием вашего персонажа!
