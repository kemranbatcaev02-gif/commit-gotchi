## ✨ Возможности

- 🐾 **7 уникальных видов питомцев** (подробнее в [SPECIES.md](SPECIES.md)):
  - 🐱 **Neko (Котик)**: Любит ласку и уютные коммиты.
  - 🦖 **Rex (Динозавр)**: Раздавливает баги первобытным грозным рыком.
  - 🦀 **Ferris (Краб)**: Быстрый, безопасный по памяти и клешнерукий краб из мира Rust.
  - 🐕 **Shiba (Сиба-ину)**: Much commits! Very speed! Настоящий верный пёс-программист.
  - 🦆 **Ducky (Резиновая уточка)**: Эксперт Rubber Duck дебага.
  - 🐉 **Ignis (Огненный Дракон)**: Страж монорепозиториев, дышит чистым огнем компиляции!
  - 🦉 **Archie (Сыч-Архитектор)**: Ночной тактик для тех, кто коммитит в 3 часа ночи.
- 🎖️ **Система уровней и рангов (XP & Levels)**:
  - Питомец получает опыт за каждый коммит, поглаживание и лакомство.
  - Ранги от `🐣 Intern Coder` до легендарного `🌟 Mythic 10x Legend`.
- 🏆 **Награды и достижения (`achievements`)**:
  - Отслеживание 6 уникальных испытаний: первый коммит, непрерывные стрики (3 и 7 дней), режим бога (20+ коммитов) и другие.
- 🏷️ **Экспорт бейджей для GitHub Profile (`export-badge`)**:
  - Генерация персонального бейджа Shields.io в формате Markdown для вставки в `README.md` профиля.
- ⚡ **Автоматический подсчет коммитов и стрика**:
  - Считывает локальную историю через `git log` и рассчитывает стрик подряд идущих рабочих дней.
- 🔥 **Шкала эмоций и состояний**:
  - `🔥 РЕЖИМ БОГА` (20+ коммитов в день): Питомец надевает крутые очки, сытость и энергия на 100%!
  - `✨ ВОСТОРГ` (5–19 коммитов): Сытый, бодрый и жизнерадостный.
  - `😊 ДОВОЛЕН` (1–4 коммита): Нормальный рабочий темп.
  - `💧 ГОЛОДАЕТ` (0 коммитов): Просит запушить хотя бы хотфикс.
  - `💀 СПЯЧКА` (несколько дней без кода): Питомец в спячке до первого пуша.
- 🖐️ **Интерактивные действия**:
  - `gotchi.py pet`: Погладить питомца (+15% к шкале счастья, +3 XP).
  - `gotchi.py feed`: Угостить коммит-снеком.
  - `gotchi.py watch`: Терминальная анимация в реальном времени.
- 📦 **Ноль внешних библиотек**: Написан на стандартной библиотеке Python 3.8+!

## 🚀 Быстрый старт

### 1. Проверить статус питомца
```bash
python gotchi.py
```

### 2. Сменить питомца
```bash
# Выбрать огнедышащего дракона
python gotchi.py --pet dragon

# Или мудрого сыча-архитектора
python gotchi.py --pet owl
```

### 3. Проверить достижения
```bash
python gotchi.py achievements
```

### 4. Сгенерировать бейдж для профиля GitHub
```bash
python gotchi.py export-badge
```

### 5. Погладить или покормить
```bash
# Погладить питомца
python gotchi.py pet

# Угостить 3 снеками
python gotchi.py feed --feed-snack 3
```

## 💡 Автозапуск в Shell профиле

Добавьте вызов `python path/to/gotchi.py status` в ваш `.bashrc`, `.zshrc` или профиль PowerShell, чтобы питомец встречал вас при каждом открытии терминала!
